[Astro](https://astro.build) 기반 정적 사이트다. 마크다운 파일 하나가 글 하나이고,

## 글 쓰는 법

### 1. 폴더 만들기

글 하나가 폴더 하나다. `src/content/posts/` 에 폴더를 만들고 그 안에
`index.md` 를 넣는다. **폴더명이 그대로 URL** 이 된다.

```
src/content/posts/
└── 키패드-누르기/          →  /posts/키패드-누르기/
    ├── index.md
    └── 그림.png
```

`제목.md` 파일 하나로 써도 동작하지만, 그러면 이미지를 넣을 때 글과 이미지가
같은 폴더에 뒤섞인다. 글이 쌓이면 금방 지저분해지므로 처음부터 폴더로 만든다.

이미지는 폴더 안에 넣고 `![설명](./그림.png)` 로 참조한다. `./` 로 시작하는
상대경로를 쓰면 Astro 가 webp 변환과 크기 최적화를 자동으로 해준다.
`public/` 에 넣고 절대경로로 참조하면 이 최적화가 적용되지 않는다.

### 2. 스니펫으로 뼈대 넣기

빈 파일에서 프리픽스를 입력하고 `Tab` 을 누르면 글 뼈대가 통째로 들어간다.
그다음부터는 `Tab` 을 누를 때마다 입력할 자리로 순서대로 이동한다.

| 프리픽스 | 넣는 것 |
|---|---|
| `ps` | PS 풀이 일지 |
| `cert` | 자격증 공부 일지 |
| `note` | 콜아웃 박스 |

#### PS 풀이 일지는 `ps` + `Tab`

| 순서 | 항목 | 입력 |
|---|---|---|
| 1 | 플랫폼 | 드롭다운 — 프로그래머스 / 백준 / 릿코드 / 코드업 |
| 2 | 문제 이름 | 직접 입력 |
| 3 | 한 줄 요약 | 직접 입력 |
| 4 | 알고리즘 태그 | 해시, DP, BFS … |
| 5 | 언어 태그 | 드롭다운 — Python / Java / C++ / JavaScript / C# |
| 6 | 공개 여부 | 드롭다운 — false(공개) / true(비공개) |
| 7 | 문제 링크 | 직접 입력 |
| 8 | 난이도 | Lv.1 … |
| 9~10 | 문제 요약, 접근 | 직접 입력 |
| 11 | 코드블록 언어 | 드롭다운 — **소문자** python / java / cpp … |
| 12 | 파일 확장자 | 드롭다운 — py / java / cpp … |
| 13~15 | 시간·공간복잡도, 배운 점 | 직접 입력 |

날짜는 오늘 날짜로 자동으로 채워지고, 1번에서 고른 플랫폼은 제목과 카테고리에
자동 반영된다.

#### 자격증 공부 일지는 `cert` + `Tab`

PS 일지와 구조가 달라 스니펫을 따로 뒀다.

| 순서 | 항목 | 입력 |
|---|---|---|
| 1 | 자격증 | 드롭다운 — 리눅스마스터 / ADSP / 정보처리기사 / SQLD / 컴활 |
| 2 | 회차 | 1일차, 2주차 … |
| 3 | 오늘 주제 | 직접 입력 |
| 4 | 필기·실기 | 드롭다운 |
| 5 | 과목명 태그 | 직접 입력 |
| 6 | 공개 여부 | 드롭다운 |
| 7 | 시험일 | 직접 입력 |
| 8~15 | 오늘 범위, 핵심 정리, 헷갈린 개념, 오답 노트, 다음에 볼 것 | 직접 입력 |

1번에서 고른 자격증은 제목과 카테고리(`자격증/…`)에 자동으로 들어간다.
3번 주제와 4번 필기·실기도 여러 자리에 함께 반영된다.

본문은 **오늘 범위 → 핵심 정리 → 헷갈린 개념 → 오답 노트 → 다음에 볼 것**
순서다. 헷갈린 개념은 `:::warning` 박스로, 오답 노트는 표로 들어간다.
틀린 이유를 적는 칸이 있는데, 여기를 채워야 나중에 다시 볼 가치가 생긴다.

#### 콜아웃 박스는 `note` + `Tab`

note / tip / important / warning / caution 중 드롭다운으로 고른다.
글 중간 아무 데서나 쓸 수 있다.

> 스니펫이 안 펼쳐지면 `Ctrl+Shift+P` → `Developer: Reload Window`.
> 그래도 안 되면 `Ctrl+Shift+P` → `Insert Snippet` 으로 목록에서 직접 고를 수 있다.

### 3. 미리보기

`Ctrl+Shift+P` → `Run Task` → **블로그 미리보기 시작**
(터미널을 쓰려면 `corepack pnpm dev`)

http://localhost:4321 에서 확인한다. 저장하면 자동 새로고침된다.

> VS Code 오른쪽의 마크다운 미리보기 패널은 이 블로그의 실제 모습이 아니다.
> `:::note` 나 코드블록 옵션을 해석하지 못하니 반드시 localhost:4321 로 볼 것.

### 4. 올리기

VS Code 왼쪽 **Source Control**(`Ctrl+Shift+G`) 에서 커밋하고 Sync.
1분쯤 뒤 사이트에 반영된다.

## frontmatter

```yaml
---
title: "[프로그래머스] 두 정수 사이의 합"
published: 2026-09-05          # 따옴표 없이
description: "Lv.1 · 기본 · 연속합"
tags: ["Python"]
category: "PS/프로그래머스"
draft: false                    # true 면 배포 사이트에 안 뜬다
lang: "ko"
---
```

### 카테고리는 슬래시로 계층을 만든다

`category` 에 `"PS/프로그래머스"` 처럼 적으면 사이드바에 트리로 표시된다.
깊이 제한은 없다.

```
PS  (9)              ← 하위 글까지 모두 합산한 숫자
  프로그래머스  (7)
  백준  (2)
개발  (3)
  C#  (3)
```

부모(`PS`)를 클릭하면 하위 글이 전부 나오고, 자식(`프로그래머스`)을 클릭하면
그것만 나온다.

플랫폼은 카테고리가 담당하므로 **태그에는 알고리즘 유형과 언어만** 적는다.

### 최상위 카테고리는 이 6개로 고정한다

빈 카테고리는 만들 수 없다. 카테고리는 글의 `category` 값에서 매 빌드마다
자동으로 만들어지므로, 글이 하나도 없는 카테고리는 사이드바에 나타나지 않는다.
그래서 규칙만 여기에 적어두고, 첫 글을 쓸 때 해당 카테고리가 생겨나게 한다.

| 최상위 | 넣는 글 | 2단계 예시 |
|---|---|---|
| `PS` | 코딩테스트 문제풀이 | `PS/프로그래머스` `PS/백준` `PS/릿코드` `PS/코드업` |
| `논문` | 논문 리뷰 | `논문/Diffusion` `논문/영상생성` |
| `수업` | 대학교 강의 | `수업/컴퓨터그래픽스` `수업/운영체제` |
| `개발` | 혼자 하는 개발 공부 | `개발/Unity` `개발/웹` |
| `자격증` | 기술 자격 | `자격증/리눅스마스터` `자격증/ADSP` `자격증/정보처리기사` |
| `어학` | 어학 시험 | `어학/JLPT` `어학/TOEIC` |

경계가 헷갈릴 때의 기준:

- **`수업` vs `개발`** — 학점이 걸려 있으면 `수업`, 아니면 `개발`.
  학교에서 들은 Unity 수업은 `수업/게임프로그래밍`, 혼자 판 건 `개발/Unity`.
- **`자격증` vs `어학`** — 기술 자격은 `자격증`, 언어 시험은 `어학`.
  JLPT 도 넓게는 자격증이지만 공부 방식과 기록 내용이 달라 분리한다.
- **`논문` vs `개발`** — 읽고 정리하면 `논문`, 직접 구현하면 `개발`.
  둘 다 하면 글을 나누거나, 주 목적 쪽에 넣고 나머지는 태그로 건다.

**2단계까지만 쓴다.** 3단계도 동작하지만 사이드바 폭이 좁아 글자가 잘린다.
세부 주제는 태그로 건다. 태그는 여러 개를 붙일 수 있어서 `#셰이더` `#URP`
같은 걸 자유롭게 쓸 수 있다.

## 자주 밟는 함정

- **코드블록 언어는 소문자.** ` ```Python ` 처럼 대문자로 쓰면 문법 강조가
  조용히 실패하고 회색 텍스트로 렌더링된다. 에러가 안 나서 알아채기 어렵다.
- **`draft: true` 인 글은 로컬에서는 보이고 배포 사이트에서만 숨는다.**
  다 쓰고 나서 `false` 로 바꾸는 걸 잊지 말 것.
- **`pnpm dev` 를 켜둔 채로 `pnpm build` 를 돌리지 말 것.** 캐시가 충돌해
  Tailwind 에러가 난다. 코드 문제가 아니다.
- **글 파일이나 이미지를 옮기거나 이름을 바꾸면 dev 서버를 재시작한다.**
  `.astro/` 캐시가 옛 경로를 붙들고 있어 500 에러가 난다. 파일 *내용* 수정은
  자동 반영되지만 이동과 이름 변경은 따라오지 못한다. 그래도 안 되면
  `.astro` 폴더를 지우고 다시 켠다.
- **`src/content/posts/` 안에 있으면 전부 글이 된다.** 하위 폴더에서는 파일명
  앞의 `_` 도 통하지 않는다. 글이 아닌 파일은 이 폴더 밖에 둘 것.

## 폴더 구조

```
src/content/posts/     글. 글 하나가 폴더 하나 (폴더/index.md + 이미지)
src/config.ts          사이트 제목, 프로필, 네비게이션, 테마
src/content/spec/      소개 페이지 내용
templates/ps.md        PS 일지 템플릿 원본 (사이트에는 안 뜸)
templates/cert.md      자격증 일지 템플릿 원본 (사이트에는 안 뜸)
docs/demo-posts/       템플릿 기본 예시 글 보관함 (사이트에는 안 뜸)
.vscode/               스니펫, 미리보기 태스크, 에디터 설정
```
